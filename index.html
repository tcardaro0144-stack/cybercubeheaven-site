How it plays

You move a glowing cube with the keyboard or a gamepad. The cube fires a piercing laser at the nearest enemy on its own, and each level you spend one skill point on a single upgrade. You can save and continue.

  • 1

    Ring Shield

    Spinning neon ring damages and repels viruses touching it.

  • 2

    Faster Laser

    Overclocks the piercing Laser Beam for shorter cooldowns.

  • 3

    Shockwave

    Installs a periodic pulse that pushes nearby viruses back.

Five sectors

The full game is 50 waves, ten in each sector. The demo is Data Vault only.

  1. 01

    Perimeter Breach

    Waves 1–10

  2. 02

    Data Vault Demo

    Waves 11–20. The demo covers this sector and stops here.

  3. 03

    Logic Core

    Waves 21–30

  4. 04

    Memory Array

    Waves 31–40

  5. 05

    Central Core

    Waves 41–50
